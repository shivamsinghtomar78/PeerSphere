# 11 — Typography

Use a modern system sans-serif stack with tabular numerals available for scores, CGPA, ranks, and dates. Define semantic styles: Display, H1, H2, H3, Title, Body, Label, Caption. Typography is responsive through tokenized sizes and line heights, not arbitrary per-screen values.

Numeric hierarchy: key score/value → status label → explanatory qualifier. Keep ordinary body copy comfortably readable; do not shrink evidence text below the accessible minimum to fit a card.

## Acceptance Criteria

- [ ] Long names and localized text wrap without truncating essential information.
- [ ] Score and rank views use stable numeral alignment.
