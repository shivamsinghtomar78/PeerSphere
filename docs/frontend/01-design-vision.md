# 01 — Design Vision

## Product Character

PeerSphere should feel calm, capable, trustworthy, and data-literate. It supports sensitive placement choices, so information hierarchy and evidence must lead decoration. The experience is Apple-inspired in restraint and composition, not a copy of Apple UI.

## Visual Direction

Use a quiet neutral canvas, opaque content surfaces, restrained semantic color, precise typography, and compact Bento grouping where it improves scanning. Apply liquid-glass treatment to navigation, filters, dialogs, and selected controls—not to every data card.

## Non-goals

Do not use neon gradients, decorative dashboards, large translucent card farms, excessive rounded corners, speculative “AI magic,” or motion that competes with reading. A match score must always carry eligibility, requirement coverage, confidence, and an explanation link.

## Acceptance Criteria

- [ ] A reviewer can identify the primary task within five seconds.
- [ ] Visual effects never reduce contrast, reading, or state clarity.
- [ ] Every AI-assisted insight has a human-readable caveat and evidence path.
