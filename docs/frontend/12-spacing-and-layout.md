# 12 — Spacing and Layout

Use a 4px base spacing scale: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64. Apply it through CSS variables/Tailwind tokens. Use narrow, medium, and wide content containers based on reading, form, or table task.

Define radii: small 8px for controls, medium 12px for ordinary surfaces, large 16px for prominent cards/sheets, XL 24px only for focal containers, and pill only for compact controls. Do not make every element fully rounded.

## Acceptance Criteria

- [ ] Alignment, gap, padding, and radius use tokens.
- [ ] Forms prioritize readable line length and clear grouping over Bento density.
