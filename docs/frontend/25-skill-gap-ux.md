# 25 — Skill Gap UX

For each gap show the skill/requirement, priority, status, why it matters, evidence state, and next action. Group by high/medium/low priority; do not bury a hard requirement behind cosmetic scoring. A detail sheet may explain prerequisites, recommended artifact, estimated scope, and link to profile update.

Empty state: “No material gaps identified in the available evidence for this job.” It must not assert mastery. Low-confidence/poor extraction outcomes show a review/correction path rather than a confident gap list.

## Acceptance Criteria

- [ ] A student can identify the highest-impact next improvement and why it matters.
