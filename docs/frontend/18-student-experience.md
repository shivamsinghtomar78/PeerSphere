# 18 — Student Experience

The student dashboard answers “How prepared am I and what should I do next?” Prioritize placement readiness, recommended jobs, active applications, match summary, high-priority gaps, and next recommendation. Let students view evidence supporting a match, correct profile/resume information, and understand that scores are recommendations—not selection guarantees.

Profile uses progressive sections: Basic Information, Education, Skills, Projects, Internships, Certifications, Assessments, Resume, Preferences. Show completion percentage and actionable missing fields. Job detail separates hard eligibility, requirements, application action, and match explanation.

## Acceptance Criteria

- [ ] A student can find their next meaningful action from the dashboard.
- [ ] Student views never reveal other candidates or undisclosed decision criteria.
