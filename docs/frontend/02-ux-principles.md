# 02 — UX Principles

1. **Clarity over decoration:** label data, actions, consequences, and status in plain language.
2. **Trust over novelty:** show evidence, confidence, freshness, and review status for AI-assisted output.
3. **Action over diagnosis:** every material skill gap links to an achievable next step.
4. **Progressive disclosure:** lead with a summary; reveal evidence, versions, and detail on demand.
5. **Consistency over invention:** reuse a documented component and state pattern.
6. **Accessible by default:** keyboard, touch, screen-reader, contrast, reduced-motion, and reduced-transparency support are requirements.
7. **Privacy by design:** show only data the current role may access; do not use comparative student data in student views.

## Acceptance Criteria

- [ ] Each screen states its primary question and primary action.
- [ ] Status never relies on color alone.
- [ ] Ambiguous or low-confidence results direct the appropriate human review.
