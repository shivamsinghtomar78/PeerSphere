# 22 — Dashboard Design

Use Bento where it clarifies the current operational picture. Student dashboard: readiness, recommended jobs, applications, match, gaps, roadmap, upcoming drives. Placement dashboard: students, active jobs, applications, eligible candidates, rankings, readiness, gap distribution, low-confidence queue, activity.

A dashboard card has a specific question, current value, comparative context when relevant, and a route to detail. Use charts only for decisions; a card must not be a decorative placeholder. Keep rankings and key actions above the fold on laptop/desktop; prioritize readiness and next steps for students on mobile.

## Acceptance Criteria

- [ ] A dashboard supports scanning plus direct drill-down without duplicating whole reports.
