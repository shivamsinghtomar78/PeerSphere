# 10 — Color System

## Semantic Tokens

| Token | Light intent | Dark intent |
|---|---|---|
| canvas | soft neutral near-white | deep neutral, not pure black |
| surface | opaque elevated neutral | subdued opaque charcoal |
| glass | controlled translucent neutral | controlled translucent deep neutral |
| text / muted | high / moderate contrast | high / moderate contrast |
| accent | one restrained institutional/brand accent | adjusted for contrast |
| success / warning / danger / info | status with icon + label | separately tuned, not inverted |

Use color to reinforce—not encode alone—eligibility, match state, confidence, and status. Reserve strong semantic color for decisions, alerts, and primary action. Gradients are optional, subtle, and never carry required meaning.

## Acceptance Criteria

- [ ] Text and interactive contrasts meet WCAG 2.2 AA targets.
- [ ] Charts use a color-blind-safe palette and direct labels/tooltips.
