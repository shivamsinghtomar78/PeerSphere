# 21 — System Administrator Experience (Future, Policy-Gated)

System administration may eventually include user management, company management, approved configuration, and audit access. It is not an implicit superuser view. Resume access and candidate evaluation detail require separate explicit privileges and audit.

Keep administrative workflows sober and table-oriented: search, filters, audit detail, confirmation for irreversible actions, and clear configuration versioning. Do not use dashboard decoration where operational records are more useful.

## Acceptance Criteria

- [ ] Any future admin screen enforces separately reviewed permissions and audit access.
