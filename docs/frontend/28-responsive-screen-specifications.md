# 28 — Responsive Screen Specification Format

Each implemented route must document: Screen Name; Purpose; Primary User; Primary Goal; Entry Points; Navigation; Layout; Information Hierarchy; Components; Primary/Secondary Actions; Responsive Behavior; Loading, Empty, Error, and Success States; Accessibility; Animation; and Acceptance Criteria.

## Required Screen Set and Priority

1. Design system and app shell
2. Student dashboard, profile, job discovery/detail
3. Match analysis, resume comparison, skill gaps, recommendations
4. Placement dashboard, candidate ranking/detail/comparison, job creation
5. Analytics/reports
6. Future recruiter/admin screens only after authorization approval

For each screen, attach viewport captures at 375px, 768px, 1024px, and 1440px plus keyboard and reduced-preference checks before acceptance.
