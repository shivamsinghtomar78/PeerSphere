# 19 — Placement Officer Experience

The placement dashboard answers “What is happening and where do I need to act?” Prioritize active jobs, applications, eligible candidate count, low-confidence/manual-review queue, ranking updates, skill-gap distribution, and recent placement activity.

Candidate rankings show rank, student identity, match score, confidence, eligibility, key skills, major gaps, freshness, and review state. Filters are server-backed and visible as applied chips. Candidate detail exposes structured evidence and a reasoned override control. Job creation is a stepper: Company → Role → Eligibility → Required skills → Preferred skills → Description → Review → Publish.

## Acceptance Criteria

- [ ] An officer can safely filter, inspect, compare, review, and record an override.
- [ ] Shortlist paths expose confidence and review requirements before confirmation.
