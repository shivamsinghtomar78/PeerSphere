# 30 — UI Implementation Roadmap

## Phase A — Foundation

Create the Next.js TypeScript app shell, Tailwind/CSS token system, light/dark/reduced-transparency themes, primitive components, icon strategy, accessibility test setup, and Storybook/component documentation if adopted.

## Phase B — Student Core

Implement student dashboard, profile, resume, job discovery/detail, applications, and all required states against typed contracts.

## Phase C — Explainable Matching

Implement match analysis, evidence list, confidence/review banner, resume comparison, skill gaps, and actionable recommendation roadmap.

## Phase D — Placement Operations

Implement placement dashboard, job stepper, candidate ranking, filters, detail, comparison, manual-review, and override experiences.

## Phase E — Quality and Release

Perform end-to-end, visual regression, performance, accessibility, localization/RTL readiness, and cross-browser checks. Add recruiter/admin UI only after their backend roles, consent model, and access policy are approved.

## Completion Rule

For every screen: read this documentation, use existing components, implement all states, test at documented breakpoints, perform accessibility/visual QA, repair defects, then update the corresponding phase evidence.
