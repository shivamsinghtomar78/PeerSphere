# 15 — Accessibility

Target WCAG 2.2 AA. Use semantic landmarks, headings, labels, native controls where possible, visible focus, logical DOM/reading order, keyboard operation, screen-reader announcements, sufficient contrast, and non-color status indicators. Dialogs trap focus, restore it on close, and expose clear names.

Offer reduced motion and reduced transparency. Respect text zoom, reflow, contrast preferences, and RTL readiness. Charts require a textual summary or accessible table. File upload, score breakdown, comparison, and filters must have keyboard paths.

## Acceptance Criteria

- [ ] Automated accessibility checks pass in CI for documented flows.
- [ ] Manual keyboard, screen-reader, zoom, contrast, and reduced-preference tests are recorded.
