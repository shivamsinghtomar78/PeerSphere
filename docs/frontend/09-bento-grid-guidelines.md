# 09 — Bento Grid Guidelines

Use a Bento grid for compact dashboard summaries, readiness overviews, candidate highlights, skill-gap summaries, activity, and meaningful analytics. Do not force it on forms, long reports, comparison tables, or dense lists.

## Grid Rules

- Desktop begins with a 12-column grid; card spans express importance, not decoration.
- Use a small, consistent gap token and aligned card edges.
- Each card answers one question and has a title, primary value/content, and direct action when actionable.
- Wide cards carry trends or rankings; small cards carry one metric.
- Reorder by task priority at smaller widths instead of preserving decorative geometry.

## Acceptance Criteria

- [ ] Every card has a purpose and useful empty state.
- [ ] No essential metric appears only in a decorative chart.
