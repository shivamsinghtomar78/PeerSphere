# 23 — Data Visualization

Use charts for placement readiness distribution, skill-gap distribution, candidate match distribution, applications by job, and placement progress only when the chart answers an identified question. Prefer bars, ordered distributions, and direct labels to decorative gauges.

Provide chart title, time/filter scope, units, legend, keyboard-accessible data table or summary, visible empty state, and explanation of unusual values. Never visualize an AI score without confidence, eligibility context, and a link to methodology/evidence.

## Acceptance Criteria

- [ ] Every chart has a decision question, accessible alternative, and no misleading axis or color encoding.
