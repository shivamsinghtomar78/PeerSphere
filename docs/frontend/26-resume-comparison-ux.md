# 26 — Resume vs Job UX

Desktop uses a readable comparison table: Job Requirement | Requirement Type | Student Evidence | Match State | Notes. Do not use an overloaded side-by-side document viewer as the primary comparison. Mobile stacks each requirement into an expandable, labeled comparison card.

Evidence snippets identify their source and location when available. Highlighted terms supplement, not replace, text labels. Allow an authorized student to report missing/outdated profile evidence; do not provide editing of the original evaluated snapshot.

## Acceptance Criteria

- [ ] Comparison remains usable at 200% zoom and on a 320px viewport.
