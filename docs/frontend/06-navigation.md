# 06 — Navigation

## Application Shell

Desktop uses a glass sidebar, compact glass header, breadcrumbs on deep routes, and an opaque/bento content area. Mobile uses a glass header and a bottom navigation containing the highest-frequency destinations; secondary destinations use an accessible sheet.

## Rules

- Highlight the current route with icon, label, and non-color indicator.
- Keep Student and Placement navigation role-specific.
- Use search as a command-like action for students, jobs, skills, and reports where supported.
- Preserve filters in URL search parameters for shareable administrator views.
- Announce route changes and restore focus appropriately.

## Acceptance Criteria

- [ ] Keyboard users can reach every destination without a pointer.
- [ ] Mobile bottom navigation has no more than five primary destinations.
