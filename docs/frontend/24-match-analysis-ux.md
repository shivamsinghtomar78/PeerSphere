# 24 — Match Analysis UX

Present match analysis in this order: overall match and caveat → eligibility → required-skill coverage → strong matches → partial matches → missing requirements → resume/profile evidence → improvement opportunities. A score card always pairs score with classification, required skills matched, confidence, algorithm/result freshness, and review state.

Use clear symbols plus text: Matched, Partial, Missing, Unknown/Needs Review. Link evidence to a resume location or profile field where available. Clearly distinguish “not demonstrated in submitted evidence” from “does not have this skill.”

## Acceptance Criteria

- [ ] The screen explains why a score exists without implying a hiring outcome.
