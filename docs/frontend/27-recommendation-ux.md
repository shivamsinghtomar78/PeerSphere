# 27 — Recommendation UX

Display recommendations as a prioritized roadmap, not a random list. Each item has: target skill/evidence, reason, 3–5 bounded steps, expected demonstrable artifact, optional profile update action, and status saved by the student. State that completing the plan can increase alignment with similar roles; it never guarantees selection.

Keep recommendations accessible and realistically scoped. Avoid recommending paid products, unsupported certifications, or activities that assume personal circumstances. Let students dismiss or mark an item planned/completed without changing the historic evaluation.

## Acceptance Criteria

- [ ] Every recommendation is traceable to a gap, requirement, or valid future-readiness pattern.
