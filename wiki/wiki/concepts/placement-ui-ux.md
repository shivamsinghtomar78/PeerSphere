# Placement UI/UX System

The frontend is designed for clarity, trust, explainability, and action. It uses **Next.js App Router with TypeScript** and a semantic token-based design system.

## Visual rule

Use opaque content for reading, tables, lists, and most data cards. Use liquid-glass treatment selectively for navigation, controls, filters, dialogs, sheets, and selected states. Use Bento layouts only for meaningful, scannable dashboard groups.

## Decision-support rule

A match result always presents eligibility, required-skill coverage, confidence, evidence path, and review state—not a bare percentage. Recommendations describe ways to increase alignment; they do not promise placement outcomes.

## Product boundaries

The MVP serves Student and Placement Administrator roles. Recruiter and system-administrator experiences remain future, policy-gated work until permissions and data-sharing behavior are explicitly approved.
