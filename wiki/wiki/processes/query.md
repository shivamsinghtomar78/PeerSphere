# Query the Wiki

1. Read [[../index|index.md]] to locate candidate notes.
2. Read the most relevant wiki pages and linked source notes; inspect raw sources when a claim is consequential or ambiguous.
3. Produce a concise answer with links to the notes/sources that support it.
4. Distinguish source-backed claims, synthesis, and inference.
5. If the answer is a reusable comparison, decision, or analysis, file it in `wiki/analyses/`, update [[../index|the index]], and append [[../log|a log entry]].

Do not answer beyond the available evidence. State the gap and propose a source or question when necessary.
