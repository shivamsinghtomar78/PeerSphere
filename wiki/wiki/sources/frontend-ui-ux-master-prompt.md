# Frontend UI/UX Master Prompt — Source Note

## Provenance

This note compiles the immutable [raw UI/UX prompt](../../raw/2026-08-15-frontend-ui-ux-master-prompt.md) supplied on 2026-08-15.

## Adopted decisions

- The frontend baseline is Next.js with TypeScript, React, Tailwind CSS, CSS variables, modern CSS, a reduced-motion-aware motion library, and one consistent icon set.
- The visual language combines a professional, information-first placement product with selective liquid-glass controls and Apple-inspired Bento grouping.
- Match, confidence, eligibility, evidence, and skill gaps must be legible and must never imply guaranteed selection.
- Accessibility, responsive transformations, UI states, and visual QA are required delivery work.
- Recruiter and administrator experiences require product/authorization approval beyond the current MVP roles.

## Adaptation boundaries

**Inference:** The reference repositories should inform principles rather than be copied. The frontend uses web-native CSS/React/Next.js patterns; it does not reuse Flutter/Dart implementation code. The Phase 4 role model remains authoritative, so future roles remain policy-gated.
